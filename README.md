# Employee Data Summary – Excel

## Project Overview
This project summarizes employee data by department, job role, and salary using Microsoft Excel.

## Objectives
- Analyze employee distribution by department.
- Compare average salaries across departments and roles.
- Practice PivotTables and grouped workforce analysis.
- Present findings using three charts.

## Tools Used
- Microsoft Excel
- PivotTables
- Charts and data summarization

## Deliverables
- Employee Data sheet
- Summary sheet
- Department-wise average salary chart
- Role-wise average salary chart
- Department-wise employee count chart

## Conclusion
This project demonstrates basic HR analytics skills by organizing employee information and comparing salary averages and workforce distribution across departments and roles.
